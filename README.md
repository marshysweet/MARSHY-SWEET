# Marshy Sweet App

Installable mobile-first PWA implementing the supplied Marshy Sweet Figma direction.

## Included flows

- Login and sign-up UI, including Google/Facebook/Apple entry points
- Home, search, rewards, recent orders and drawer navigation
- Boba tea, tea, coffee, bulk candy, gift and fun-stuff product catalog
- Product details, favorites and cart
- Pickup/delivery totals, NJ tax and order tracking UI
- Rewards, order history, profile, payment methods, settings, privacy and help
- Offline shell via service worker

## Run locally

```bash
npx serve .
```

The current repository is the independent Marshy Sweet frontend. Payment buttons are presentation-only until connected to the production backend/payment contract.
